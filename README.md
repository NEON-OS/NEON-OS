
# NEON OS

A Debian-based Linux operating system built around a clean XFCE desktop and a neon-inspired design.

## Features
- Debian Linux base
- XFCE Desktop Environment
- LightDM Display Manager
- GRUB bootloader
- Live boot ISO
- VirtualBox compatibility
- Custom NEON OS configuration

## Build
NEON OS is built using Debian Live Build and GitHub Actions.
